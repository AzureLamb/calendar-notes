# 📅 calendar-notes

A lightweight, date-first calendar app designed for frictionless daily notes.

## Why Built
I wanted a calendar tool with a simple, sleek look to write quick notes on specific days, but I couldn't find one that worked the way I wanted. So I built it myself in **2.5 hours**.
Existing solutions were either too bloated with features I didn't need or lacked a clear, single-click daily note interface. calendar-notes was created to solve one problem.

## Tech Stack
- **Runtime:** [Node.js](https://nodejs.org/)
- **Architecture:** Monolithic
- **Storage:** Local file system

## How to Run

1. Clone the repository:
```Bash
git clone https://github.com/AzureLamb/calendar-notes.git
cd calendar-notes
```
2. Install dependencies
```Bash
npm install
```
3. Launch the application
```Bash
node src/backend/server.ts
```
